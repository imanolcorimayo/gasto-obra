# Instagram Content Strategy — GastoObra

## Reel Hook Patterns

### Pattern Break (from viral analysis)
Setup → Break → Reveal. The viewer enters with one expectation, the video breaks it cleanly.

**Emotional triggers in the setup:**
- Sympathy / Empathy (relatable situation)
- Humor (unexpected behavior)
- Recognition ("I've been there")

**The break:** Focus shifts — the subject becomes the author, the context flips, or the product interrupts the scene. Must be clean, cinematic, and professional. Not gimmicky.

**For GastoObra:** Show a relatable pain (messy receipts, WhatsApp chaos with clients, spreadsheet hell) → break → the product solves it. The transition should feel like a "bait and switch" that earns respect, not annoyance.

---

## Reel Catch Principles

1. **Hook in first 2 seconds** — Bold visual + provocative text. No logo, no intro. Start mid-action or with a tension-creating statement.
2. **Pattern interrupt every 3-4 seconds** — Change scale, movement, color, or position. Steady = scroll.
3. **Text on screen always** — 85%+ watch on mute. Short, punchy phrases. Max 8-10 words visible at once.
4. **Progressive reveal** — Each scene answers one question and creates the next: "What is this?" → "How?" → "What do I get?" → "Where?"
5. **End with recognition** — Last 3 seconds: logo, name, tagline. Simple, bold, held long enough to burn in.

## Visual Effects Toolkit

| Effect | When to use | Impact |
|---|---|---|
| Zoom + tilt + break container | Highlighting key UI elements | "Look at THIS specifically" |
| Parallax layers | Scene transitions | Depth, premium feel |
| Scale slam | Brand reveal, key stats | Drop in from 1.5x→1x with bounce — urgency |
| Staggered cascade | Feature lists, expense rows | Items slide in 100ms apart — rhythm |
| Glow pulse | Key numbers, CTA | Subtle amber glow breathes — draws the eye |
| Cinematic crop → reveal | Phone/dashboard scenes | Start zoomed into detail, pull back to full UI |
| Hard cut + flash | Between major sections | White/amber flash — energy, pace |
| Float/drift | Background elements | Subtle Y-axis movement — feels alive |
| Pop-out (animated) | Bot response, KPIs | Element animates from inside container to popped-out — dynamic |

## Reel Structure Template (25-30s)

| Time | Scene | Purpose |
|---|---|---|
| 0-2s | Hook — bold stat or question | Tension, stop the scroll |
| 2-6s | Core feature demo | "How?" curiosity |
| 6-10s | Feature breadth | Capability density |
| 10-15s | Product in action | Credibility |
| 15-20s | Key value prop | Payoff |
| 20-25s | Mission / emotional anchor | Connection |
| 25-30s | Brand lock — logo + tagline | Recognition |
